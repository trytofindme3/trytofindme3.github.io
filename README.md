# EcoBot – Chatbot/Voicebot (Course Exercise)

A simple **rule-based chatbot** created as a course exercise.  
The demo page contains the project description and (optionally) an embedded chat widget.

## 🎯 Goal / Purpose
EcoBot helps users navigate basic topics related to eco-friendly products and energy saving.  
It answers common questions using **4–5 predefined responses** and reduces the need to contact support.

## 🛠 Tools Used
- **Chatbot.com** — building the chatbot (blocks, buttons, scripted replies)
- **GitHub Pages** — hosting the demo webpage

## 📚 Knowledge Base
- Company FAQ (typical customer questions)
- Basic product info (e.g., solar panels, smart thermostats)
- General information about subsidy programs (e.g., “New Green Savings” / local equivalent)
- Basic warranty/complaint (returns) process

## 🙂 Bot Personality
Friendly, clear, short, supportive tone.  
Target audience: customers and the general public.

## ▶️ How to Use
1. Open the demo website (GitHub Pages link).
2. Click the chat widget in the bottom-right corner.
3. Choose a menu option or type a question.

## 🧩 What the Bot Can Answer (Summary)
- Energy saving recommendations
- Subsidies / grants
- Complaints / returns (warranty)
- Contact information
- Fallback (unknown input) + conversation closing message

## 📝 Reflection (Short)
- Strength: fast responses and simple navigation.
- Challenge: selecting the best “typical” questions and keeping answers short but useful.
- Future improvement: more scenarios, synonym handling, handoff to a human agent, optional voicebot.

- `index.html` — demo page + embedded widget code
